---
title: MCP 集成
---

MCP（[Model Context Protocol](https://modelcontextprotocol.io/)）让 Agent 可以连接外部的 MCP 服务器，自动获得其提供的工具、资源和提示词模板能力。

> 与其他 Agent 子系统不同，MCP 服务器目前**仅能由用户在管理页手动配置**，脚本没有对应的 `CAT.agent.mcp` 管理 API。脚本能感知到的，只是这些服务器提供的工具会在对话中被自动调用。

## 配置一个 MCP 服务器

在管理面板 → **Agent → MCP** 中添加：

| 字段 | 说明 |
|------|------|
| 名称 | 服务器的显示名称 |
| URL | Streamable HTTP 接口地址（JSON-RPC 2.0 over POST） |
| API Key | 可选，用于鉴权 |
| 自定义请求头 | 可选 |
| 启用 | 是否启用该服务器 |

ScriptCat 的 MCP 客户端使用 **Streamable HTTP** 传输方式，支持协议版本 `2025-03-26`。

一个 MCP 服务器可以提供三类能力：

| 能力 | 说明 |
|------|------|
| **工具（Tools）** | 会自动注册为 Agent 可调用的工具 |
| **资源（Resources）** | 可读取的资源（文本/二进制） |
| **提示词模板（Prompts）** | 支持参数的提示词模板 |

## 在对话中使用

已启用的 MCP 服务器提供的工具会自动出现在 Agent 对话可用的工具列表中，命名规则为 `mcp_{服务器名称经过安全字符处理}_{toolName}`，AI 会根据用户意图自动决定是否调用。这与 [Skill](../skill-install) 的自动加载机制类似——脚本开发者通常不需要关心底层细节。

如果需要判断某个 MCP 工具是否可用，可以在对话中直接询问 AI，或者在管理页的服务器详情中查看已发现的工具列表。
