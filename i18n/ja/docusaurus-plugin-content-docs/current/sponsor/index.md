ScriptCat はボランティアによって維持されているオープンソースプロジェクトであり、後ろ盾となる企業はありません。サーバー、ドメイン、その他のインフラに加え、開発と保守に費やされる多大な時間も、すべてコミュニティの支援によって支えられています。皆さんの支援のひとつひとつが ScriptCat の前進につながります。

## スポンサーシップの使途

スポンサーシップの収入は主に次の用途に使われます:

- **運営コストの負担** — サーバー、ドメイン、その他の日常的なインフラ
- **メンテナーと貢献者への報酬** — 長期的に携わってきたメンテナーや、コード・翻訳・ドキュメントを提供してくれるすべての人に、ふさわしい報酬を届けるため
- **新機能の開発** — 体験の向上と新機能の開発により多くの時間を充てるため

## 支援方法

個人でも企業でも、金額の大小にかかわらず、すべての支援が役に立ちます。

[OpenCollective](https://opencollective.com/scriptcat) を通じてスポンサーシップを受け付けています。一回限りまたは毎月の支援が可能で、寄付後はサポーターリストに名前が表示されます。

**スポンサー枠**（README、ウェブサイト、ドキュメントにロゴと紹介文を掲載）をご希望の場合は、[codfrm@gmail.com](mailto:codfrm@gmail.com) までご連絡ください。

## スポンサー枠

スポンサーのロゴと紹介文は、メールで調整のうえ、以下の場所に表示できます:

| 掲載場所 | 形式 |
| --- | --- |
| GitHub README の上部 | 大きなバナー |
| GitHub README のスポンサーエリア | ロゴ + 1行の紹介文 |
| ウェブサイトのスポンサーページ（このページ） | ロゴ + 紹介文 |
| ウェブサイトのドキュメントページ（例: 更新履歴） | ロゴの表示 |
