## ScriptCat について

Tampermonkey のデザインに触発され、Tampermonkey のスクリプトと互換性を持つ ScriptCat は、バックグラウンドスクリプトの実行フレームワークを実装し、スクリプトの可能性を広げるさまざまな特別な API を提供します。また、スクリプトコードの作成と開発をより快適でスムーズにする優れたエディターも備えています。

開発ロードマップについては、開発計画を公開している[プロジェクト #1](https://github.com/scriptscat/scriptcat/projects/1)を参照してください。ご提案があれば、お気軽に[issue](https://github.com/scriptscat/scriptcat/issues)を開いてお知らせください。

**役に立つと思われたら、ぜひ Star をお願いします ❤❤❤**

## Tampermonkey 中国語フォーラム
> [こちらからアクセス](https://bbs.tampermonkey.net.cn/)

Tampermonkey 中国語フォーラムは、Tampermonkey スタイルのスクリプトを開発・議論するために私たちが作ったコミュニティです。フォーラムには豊富なスクリプト学習リソースと経験豊富なメンバーが多く、そこで議論したり質問したりできます。また、スクリプトの公開とインストールもサポートしており、誰でも自由に自分の作品を共有できます。
