## 開発者モード / ユーザースクリプトの権限

#### Q: ScriptCat に「開発者モードが有効になっていません」と表示され、スクリプトが実行されません。

Chrome 120+ 以降および新しいバージョンの Edge では、スクリプトを実行するための権限をユーザーが手動で有効にする必要があります。設定手順については、[ブラウザのユーザースクリプトサポートを有効にする](/docs/use/open-dev/)を参照してください。

すでに有効にしているのに警告が表示され続ける場合は、ブラウザを再起動するか、拡張機能を再読み込みしてみてください。

## スクリプトが動作しない

#### Q: スクリプトをインストールしたのに効果がありません。

1. **「ユーザースクリプトを許可」が有効になっていない** — [ブラウザのユーザースクリプトサポートを有効にする](/docs/use/open-dev/)を参照してください
2. **コールドスタート** — ブラウザを初めて開いたとき、スクリプトがすぐに読み込まれない場合があります。ページを更新してみてください
3. **拡張機能の競合** — 広告ブロッカー（例: uBlock Origin）がスクリプトエラーを引き起こすことがあります

#### Q: スクリプトは Tampermonkey では動作するのに、ScriptCat では動作しません。

ScriptCat と Tampermonkey では API の実装にいくつかの違いがあります。最新バージョンに更新してください。問題が解決しない場合は、[GitHub](https://github.com/scriptscat/scriptcat/issues) で Issue を報告してください。

## クラウド同期の問題

> 基本的な同期の使い方については、[同期とバックアップ](/docs/use/sync/)を参照してください。

#### Q: OneDrive / Google Drive / WebDAV の同期に問題があります。

1. **削除したスクリプトが再び表示される** — すべてのデバイスで「削除の同期」が有効になっていることを確認してください

## スクリプトのインストールに関する問題

> スクリプトのインストール方法については、[スクリプトをインストールする](/docs/use/script_installation/)を参照してください。

## Cookie 認証の問題

#### Q: GM_cookie で Cookie を取得できません。

1. **認証ポップアップが表示されない** — スクリプトの `@grant` に `GM_cookie` が正しく宣言されていることを確認し、`@connect` でアクセスする必要のあるドメインを宣言してください

## スクリプトデータの消失

#### Q: ブラウザを開いた後、すべてのスクリプトが消えました。

1. **初期化の遅延** — ブラウザ起動時に ScriptCat がまだデータを読み込んでいる可能性があります。数秒待つか、ブラウザを再起動してください
2. **クリーンアップソフトウェア** — 360 Security Guard や CCleaner などのツールが拡張機能のデータを消去することがあります。クリーンアップ設定でブラウザ拡張機能のデータを除外してください
3. **定期的なバックアップを推奨** — エクスポート機能または[クラウド同期](/docs/use/sync/)を使用して、スクリプトと設定を定期的にバックアップしてください
