# 🎉 ScriptCat へようこそ

ScriptCat ブラウザ拡張機能のインストールが正常に完了しました。おめでとうございます！ScriptCat は Tampermonkey のスクリプトと互換性のある強力なユーザースクリプトマネージャーで、さらに多くの強力な機能を提供します。

<GithubStar variant="bar" scene="install" />

## セキュリティに関する注意

⚠️ **ユーザースクリプトは強力な機能を持つため、セキュリティは非常に重要です！**

ユーザースクリプトは強力な機能を持ち、ウェブページのコンテンツにアクセスして変更できるため、**セキュリティは非常に重要です**。個人情報とデバイスの安全性を守るために、以下の点に注意してください:

- ✅ **信頼できるスクリプトサイトからのみスクリプトをインストールする**
- ✅ **スクリプトの評価とユーザーのコメントを注意深く確認する**
- ✅ **スクリプトの機能と権限要件を理解する**
- ❌ **不明または不審なソースからスクリプトをダウンロードしない**
- ❌ **出所不明のスクリプトファイルをインストールしない**

### 推奨される信頼できるスクリプトソース

以下のスクリプトサイトからスクリプトを入手することをお勧めします:

- **[ScriptCat スクリプトサイト](https://scriptcat.org/)** - ScriptCat が運営する公式スクリプトサイト
- **[GreasyFork](https://greasyfork.org/)** - 世界最大のユーザースクリプトサイト
- **[Userscript.Zone](https://www.userscript.zone/)** - 厳選された高品質のスクリプト

## 次のステップ

### スクリプト管理画面にアクセスする

ブラウザのツールバーにある ScriptCat アイコンをクリックし、右上の「⚙️」歯車ボタンをクリックして管理画面に入ります。

### 最初のスクリプトを取得する

ポップアップ画面で、右上の「⋮」メニューをクリックし、「スクリプトを取得」を選択すると、公式スクリプトサイトでスクリプトを検索・インストールできます。

### 機能を試す

- 📊 **スクリプト管理**: スクリプトの有効化/無効化、実行状態の確認
- 🔧 **カスタム設定**: スクリプトのパラメータと実行ルールを設定
- 📝 **スクリプト編集**: 自分でスクリプトを作成・編集
- 🔄 **データ同期**: 複数のデバイス間でスクリプト設定を同期

## 利用上の推奨事項

1. **小さく始める**: 新規ユーザーは、シンプルで評価の高いスクリプトから始めることをお勧めします
2. **定期的な確認**: インストールしたスクリプトを定期的に確認・更新する
3. **設定のバックアップ**: 重要なスクリプト設定はバックアップしてください
4. **問題の報告**: 問題が発生した場合は、[GitHub](https://github.com/scriptscat/scriptcat)または公式コミュニティを通じてフィードバックできます

- ScriptCat はスクリプトの実行環境を提供しますが、サードパーティのスクリプトの安全性、機能、内容については責任を負いません
- サードパーティのスクリプトを使用するリスクはご自身で負うものとします
- スクリプトのソースコードとドキュメントを注意深く読み、その機能を理解していることを確認することをお勧めします
