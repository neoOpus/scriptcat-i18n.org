## 同期

スクリプトが更新されると、すぐにクラウドに同期されます。ただし、クラウドのデータが変更された場合、ローカルにスキャンして同期するまでに時間がかかります。複数のデバイスで同じクラウドストレージを共有している場合は、この点にご注意ください。

スクリプト同期セクションで保存をクリックすると、すぐに完全な同期が実行されます。
