## Synchronisierung

Wenn ein Skript aktualisiert wird, wird es sofort mit der Cloud synchronisiert. Wenn sich jedoch Cloud-Daten ändern, dauert es eine Weile, bis die Änderungen gescannt und lokal synchronisiert werden. Bitte beachten Sie dies, wenn mehrere Geräte denselben Cloud-Speicher verwenden.

Wenn Sie im Skriptsynchronisierungsbereich auf Speichern klicken, wird sofort eine vollständige Synchronisierung durchgeführt.
