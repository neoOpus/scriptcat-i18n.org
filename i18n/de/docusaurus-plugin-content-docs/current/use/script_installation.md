## Installationsschritte für verschiedene Websites

### ScriptCat-Community

[ScriptCat-Community](https://scriptcat.org/search) Offizielle ScriptCat-Website

### Userscript.Zone

[Userscript.Zone](https://www.userscript.zone/) ist eine neue Website, mit der Sie Benutzerskripte suchen können, indem Sie geeignete URLs oder Domains eingeben.

- **Große Menge an Skriptressourcen**
- **Einfach geeignete Benutzerskripte finden**
- **Zeigt nur Benutzerskripte von geprüften Benutzerskriptseiten oder zumindest von Seiten mit Kommentarfunktion**

### GreasyFork

[GreasyFork](https://greasyfork.org/) ist eine weit verbreitete Plattform zum Hosten und Teilen von Benutzerskripten, auf der Entwickler Skripte veröffentlichen und Benutzer browserbasierte Skripte installieren können, die die Funktionalität von Websites erweitern oder verändern. Die Website wurde von Jason Barnabe erstellt und ist für ihren Fokus auf Sicherheit und Open-Source-Transparenz bekannt; sie bietet eine große Sammlung von Skripten zur Verbesserung des Browsing-Erlebnisses.

Jason Barnabe ist auch der ursprüngliche Ersteller der Browsererweiterung Stylish. [Stylish](https://userstyles.org/) wurde jedoch 2016 verkauft und wird heute von einem anderen Unternehmen betrieben, ohne direkte Beteiligung von Jason Barnabe an der späteren Entwicklung.

- **Große Menge an Skriptressourcen**
- **Verfügt über die Möglichkeit, Skripte von Github zu synchronisieren**
- **Sehr aktives Open-Source-Entwicklungsmodell**

### OpenUserJS

[OpenUserJS](https://openuserjs.org/) wurde nach GreasyFork erstellt. Es wurde von Sizzle McTwizzle gegründet und verfügt ebenfalls über eine große Menge an Skriptressourcen in seinem Repository.

- **Verfügt über die Möglichkeit, Skripte von Github zu synchronisieren und Skripte zu forken**
- **Sehr aktives Open-Source-Entwicklungsmodell**

### GitHub/Gist

Sie können in Github und Gist nach Skriptressourcen suchen.


## Manuelle Skriptinstallation

1. Klicken Sie auf das ScriptCat-Erweiterungssymbol
2. Klicken Sie in der Oberfläche auf die „Zahnrad-Schaltfläche", um die ScriptCat-Verwaltungsoberfläche zu öffnen
3. Klicken Sie oben rechts auf die Schaltfläche „Neues Skript erstellen" (in der Regel genügt ein normales Skript)
4. Fügen Sie den Skriptcode in die Popup-Seite ein
5. Drücken Sie `ctrl + s`, um die Änderungen zu speichern
6. Kehren Sie zur Verwaltungsoberfläche zurück, um Ihr neu erstelltes Skript zu sehen
