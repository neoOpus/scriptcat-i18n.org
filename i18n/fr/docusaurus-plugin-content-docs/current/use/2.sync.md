# Synchronisation et Sauvegarde de vos scripts

ScriptCat vous permet de sauvegarder vos scripts et de les synchroniser entre plusieurs navigateurs ou appareils.

## Stockage Cloud supporté

ScriptCat supporte les plateformes de stockage cloud suivantes pour la synchronisation :

- **Dropbox** : Recommandé pour sa stabilité et sa rapidité.
- **Google Drive** : Support complet pour la sauvegarde de vos scripts.
- **OneDrive** : Supporté nativement.
- **WebDAV** : Utilisez votre propre serveur (Nextcloud, Synology, etc.).
- **Amazon S3** : Pour les utilisateurs avancés et les entreprises.

## Comment activer la synchronisation

1. Cliquez sur l'icône ScriptCat dans votre navigateur.
2. Allez dans le **Panneau de configuration** (icône d'engrenage).
3. Sélectionnez l'onglet **Paramètres > Synchronisation**.
4. Choisissez votre plateforme préférée et suivez les instructions d'authentification.

## Sauvegarde manuelle (Import/Export)

Vous pouvez également exporter vos scripts manuellement sous forme de fichier JSON ou ZIP pour une sauvegarde locale.

1. Dans le panneau de gestion ScriptCat, allez dans **Outils**.
2. Utilisez les boutons **Exporter** pour télécharger vos scripts.
3. Pour restaurer, utilisez le bouton **Importer** et sélectionnez votre fichier de sauvegarde.

:::tip Compatibilité
ScriptCat peut importer des fichiers de sauvegarde provenant de Tampermonkey et Violentmonkey.
:::
