# Activer le support des scripts utilisateur dans le navigateur

En raison des restrictions des navigateurs, les extensions sont désormais contraintes de passer au Manifest V3 (MV3). Les extensions Manifest V2 seront complètement abandonnées après juin 2025.

Pour continuer à utiliser ScriptCat (version MV3) et exécuter des scripts utilisateur, vous devez activer une option spécifique dans votre navigateur.

## Activer les "User Scripts" (Recommandé) {#activer-user-scripts}

Dans les versions récentes de Chrome (v138+) et Edge (v144+), une nouvelle option dédiée permet d'autoriser les scripts utilisateur sans activer globalement le mode développeur.

### Pour Microsoft Edge

1. Ouvrez la page des extensions (`edge://extensions/`).
2. Cliquez sur **Détails** sous l'extension ScriptCat.
3. Recherchez l'option **Autoriser les scripts utilisateur** et activez-la.

![edge-allow-user-scripts](./img/5.open-dev.assets/edge-allow-user-scripts.png)

### Pour Google Chrome

1. Ouvrez la page des extensions (`chrome://extensions/`).
2. Activez l'interrupteur **Mode développeur** en haut à droite (nécessaire pour voir l'option).
3. Cliquez sur **Détails** sous l'extension ScriptCat.
4. Activez l'option **Autoriser les scripts utilisateur**.

## Activer le mode développeur {#activer-mode-developpeur}

Si votre navigateur ne propose pas encore l'option spécifique ci-dessus, vous devez activer le mode développeur pour que ScriptCat puisse fonctionner.

1. Accédez à la page de gestion des extensions de votre navigateur :
   - **Chrome :** `chrome://extensions/`
   - **Edge :** `edge://extensions/`
2. Localisez l'interrupteur **Mode développeur** (généralement en haut à droite ou dans la barre latérale gauche) et activez-le.

![chrome-developer-mode-toggle](./img/5.open-dev.assets/chrome-developer-mode-toggle.webp)

## Pourquoi est-ce nécessaire ?

Le Manifest V3 renforce la sécurité en limitant l'exécution de code arbitraire. Pour qu'un gestionnaire de scripts puisse injecter vos scripts personnalisés dans les pages web, le navigateur exige une confirmation explicite de l'utilisateur (via le mode développeur ou l'option User Scripts) afin de garantir que vous avez le contrôle total sur ce qui est exécuté.
