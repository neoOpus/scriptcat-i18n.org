## À propos de ScriptCat

ScriptCat est un gestionnaire de scripts utilisateur puissant, inspiré par la philosophie de conception de Tampermonkey et entièrement compatible avec ses scripts. Il ne supporte pas seulement les scripts utilisateur traditionnels, mais implémente également de manière innovante un cadre d'exécution de scripts d'arrière-plan avec de riches extensions API, permettant aux scripts d'accomplir des fonctions encore plus puissantes. Il dispose d'un excellent éditeur de code intégré avec complétion intelligente et vérification de la syntaxe, rendant le développement de scripts plus efficace et fluide.

Pour nos plans de développement, veuillez consulter : [Projet #1](https://github.com/scriptscat/scriptcat/projects/1). Nous y publions nos plans de développement. Si vous avez de bonnes suggestions, vous pouvez également nous faire part de vos commentaires via [issue](https://github.com/scriptscat/scriptcat/issues).

**Si vous le trouvez utile, n'hésitez pas à nous donner une étoile (Star) sur GitHub ❤❤❤**

## Tampermonkey Chinois (BBS)
> [Visiter](https://bbs.tampermonkey.net.cn/)

Le forum Tampermonkey Chinois est une communauté de développement et d'échange de scripts que nous avons créée. Sur le forum, nous avons des ressources d'apprentissage très riches et de nombreux experts avec qui vous pouvez échanger et à qui vous pouvez poser des questions. Nous proposons également la publication et l'installation de scripts, afin que tout le monde puisse partager librement ses créations.
