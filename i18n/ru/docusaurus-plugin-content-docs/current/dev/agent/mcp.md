---
title: Интеграция MCP
---

MCP ([Model Context Protocol](https://modelcontextprotocol.io/)) позволяет Agent подключаться к внешним MCP-серверам и автоматически получать доступ к предоставляемым ими инструментам, ресурсам и шаблонам промптов.

> В отличие от других подсистем Agent, MCP-серверы на данный момент **можно настроить только вручную на странице управления** — API `CAT.agent.mcp` для скриптов не существует. Скрипт может лишь наблюдать, что инструменты этих серверов автоматически вызываются в ходе диалога.

## Настройка MCP-сервера

Добавьте его на странице управления → **Agent → MCP**:

| Поле | Описание |
|------|------|
| Название | Отображаемое имя сервера |
| URL | Адрес Streamable HTTP (JSON-RPC 2.0 поверх POST) |
| API Key | Необязательно, для аутентификации |
| Пользовательские заголовки | Необязательно |
| Включён | Активен ли сервер |

MCP-клиент ScriptCat использует транспорт **Streamable HTTP** и поддерживает версию протокола `2025-03-26`.

MCP-сервер может предоставлять три вида возможностей:

| Возможность | Описание |
|------|------|
| **Tools** | Автоматически регистрируются как инструменты, доступные Agent |
| **Resources** | Читаемые ресурсы (текст/бинарные) |
| **Prompts** | Шаблоны промптов с поддержкой параметров |

## Использование в диалоге

Инструменты включённых MCP-серверов автоматически появляются в списке инструментов, доступных диалогам Agent, с именами вида `mcp_{имя сервера}_{toolName}` — AI сам решает, вызывать ли их, исходя из намерений пользователя. Это работает похоже на автоматическую загрузку [Skill](../skill-install) — разработчику скрипта обычно не нужно вникать в детали реализации.

Чтобы проверить, доступен ли конкретный MCP-инструмент, можно просто спросить AI прямо в диалоге, либо посмотреть список обнаруженных инструментов в деталях сервера на странице управления.
