O ScriptCat é um projeto de código aberto mantido por voluntários, sem nenhuma empresa por trás. Servidores, domínios e outras infraestruturas, juntamente com uma grande quantidade de tempo de desenvolvimento e manutenção, são sustentados pelo apoio da comunidade. Cada contribuição ajuda o ScriptCat a ir mais longe.

## Para onde vai o seu patrocínio

A receita do patrocínio é destinada principalmente a:

- **Cobrir os custos de operação** — servidores, domínios e outras infraestruturas do dia a dia.
- **Recompensar mantenedores e colaboradores** — para que mantenedores de longo prazo e todos que enviam código, traduções e documentação recebam a recompensa que merecem.
- **Criar novos recursos** — mais tempo para aprimorar a experiência e desenvolver novas capacidades.

## Como patrocinar

Seja você uma pessoa ou uma empresa, e não importa o valor, todo apoio conta.

Coletamos patrocínios por meio do [OpenCollective](https://opencollective.com/scriptcat), com contribuições únicas ou mensais; seu nome aparecerá na lista de apoiadores após a doação.

Se você quiser um **espaço de patrocinador** — seu logotipo e uma introdução exibidos no README, no site ou na documentação — envie um e-mail para [codfrm@gmail.com](mailto:codfrm@gmail.com).

## Espaços de patrocinador

O logotipo e a descrição de um patrocinador podem ser exibidos nos seguintes lugares, combinados por e-mail:

| Local | Formato |
| --- | --- |
| Topo do README do GitHub | Banner grande |
| Área de patrocinadores do README do GitHub | Logotipo + introdução de uma linha |
| Página de patrocinadores do site (esta página) | Logotipo + introdução |
| Páginas de documentação do site (ex.: changelog) | Exibição do logotipo |
