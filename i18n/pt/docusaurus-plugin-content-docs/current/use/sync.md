## Sincronização

Quando um script é atualizado, ele é sincronizado imediatamente com a nuvem. No entanto, quando os dados na nuvem mudam, leva algum tempo para digitalizá-los e sincronizá-los localmente. Observe isso quando vários dispositivos compartilharem o mesmo armazenamento em nuvem.

Clicar em Salvar na seção de sincronização de scripts realizará imediatamente uma sincronização completa.
