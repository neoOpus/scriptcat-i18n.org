# 🎉 Bem-vindo ao ScriptCat

Parabéns por instalar com sucesso a extensão de navegador ScriptCat! O ScriptCat é um poderoso gerenciador de scripts de usuário compatível com os scripts do Tampermonkey e oferece muitos outros recursos poderosos.

<GithubStar variant="bar" scene="install" />

## Aviso de segurança

⚠️ **Os scripts de usuário têm capacidades poderosas, a segurança é crucial!**

Os scripts de usuário têm capacidades poderosas e podem acessar e modificar o conteúdo das páginas da web, portanto **a segurança é crucial**. Para proteger suas informações pessoais e a segurança do seu dispositivo, certifique-se de:

- ✅ **Instalar apenas scripts de sites de scripts confiáveis**
- ✅ **Revisar cuidadosamente as avaliações e comentários dos usuários sobre os scripts**
- ✅ **Entender a funcionalidade e os requisitos de permissão dos scripts**
- ❌ **Evitar baixar scripts de fontes desconhecidas ou suspeitas**
- ❌ **Não instalar arquivos de scripts de origem desconhecida**

### Fontes de scripts confiáveis recomendadas

Recomendamos obter scripts dos seguintes sites:

- **[Site de scripts do ScriptCat](https://scriptcat.org/)** - Site oficial de scripts mantido pelo ScriptCat
- **[GreasyFork](https://greasyfork.org/)** - O maior site de scripts de usuário do mundo
- **[Userscript.Zone](https://www.userscript.zone/)** - Scripts de alta qualidade selecionados

## Próximas etapas

### Acessar a interface de gerenciamento de scripts

Clique no ícone do ScriptCat na barra de ferramentas do navegador e, em seguida, no botão de engrenagem "⚙️" no canto superior direito para entrar na interface de gerenciamento.

### Obter seu primeiro script

Na interface pop-up, clique no menu "⋮" no canto superior direito e selecione "Obter scripts" para ir ao site oficial de scripts e pesquisar e instalar scripts.

### Explorar recursos

- 📊 **Gerenciamento de scripts**: habilitar/desabilitar scripts, ver o status de execução
- 🔧 **Configurações personalizadas**: configurar parâmetros de scripts e regras de execução
- 📝 **Edição de scripts**: criar e editar seus próprios scripts
- 🔄 **Sincronização de dados**: sincronizar suas configurações de scripts em vários dispositivos

## Recomendações de uso

1. **Comece pequeno**: recomenda-se que novos usuários comecem com scripts simples e bem avaliados
2. **Verificações regulares**: verifique e atualize regularmente seus scripts instalados
3. **Backup de configurações**: configurações importantes de scripts devem ser salvas em backup
4. **Relatar problemas**: se você encontrar problemas, pode enviar comentários por meio do [GitHub](https://github.com/scriptscat/scriptcat) ou da comunidade oficial

## Aviso legal

Ao usar o ScriptCat, você precisa entender:

- O ScriptCat fornece um ambiente de execução de scripts, mas não é responsável pela segurança, funcionalidade ou conteúdo de scripts de terceiros
- Você assume os riscos de usar scripts de terceiros
- Recomenda-se ler atentamente o código-fonte e a documentação dos scripts para garantir que você entenda sua funcionalidade

Para os termos completos do aviso legal, consulte: [Aviso legal completo](/docs/use/policy/disclaimer/)
