## Pasos de instalación desde varios sitios web

### Comunidad de ScriptCat

[Comunidad de ScriptCat](https://scriptcat.org/search) Sitio oficial de ScriptCat

### Userscript.Zone

[Userscript.Zone](https://www.userscript.zone/) es un nuevo sitio web que permite buscar scripts de usuario ingresando las URL o dominios apropiados.

- **Gran cantidad de recursos de scripts**
- **Fácil encontrar scripts de usuario adecuados**
- **Solo muestra scripts de usuario de páginas revisadas o, al menos, de páginas con funcionalidad de comentarios**

### GreasyFork

[GreasyFork](https://greasyfork.org/) es una plataforma ampliamente utilizada para alojar y compartir scripts de usuario, que permite a los desarrolladores publicar y a los usuarios instalar scripts basados en el navegador que mejoran o modifican la funcionalidad de los sitios web. El sitio fue creado por Jason Barnabe y es conocido por su énfasis en la seguridad y la transparencia de código abierto, y ofrece una gran colección de scripts para mejorar la experiencia de navegación.

Jason Barnabe también es el creador original de la extensión de navegador Stylish. [Stylish](https://userstyles.org/) se vendió en 2016 y ahora es operado por una empresa diferente, sin participación directa de Jason Barnabe en su desarrollo posterior.

- **Gran cantidad de recursos de scripts**
- **Tiene la capacidad de sincronizar scripts desde Github**
- **Modelo de desarrollo de código abierto muy activo**

### OpenUserJS

[OpenUserJS](https://openuserjs.org/) se creó después de GreasyFork. Fue creado por Sizzle McTwizzle y, de manera similar, también tiene una gran cantidad de recursos de scripts en su repositorio.

- **Tiene la capacidad de sincronizar scripts desde Github y bifurcar (fork) scripts**
- **Modelo de desarrollo de código abierto muy activo**

### GitHub/Gist

Puede buscar recursos de scripts en Github y Gist.


## Instalación manual de scripts

1. Haga clic en el icono de la extensión de ScriptCat
2. Haga clic en el "botón de engranaje" de la interfaz para entrar en la interfaz de gestión de ScriptCat
3. Haga clic en el botón "Crear nuevo script" en la esquina superior derecha (generalmente basta con crear un script normal)
4. Pegue el código del script en la página emergente
5. Presione `ctrl + s` para guardar los cambios
6. Vuelva a la interfaz de gestión para ver su script recién creado
