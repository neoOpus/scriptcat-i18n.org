---
title: Instalación de scripts
---

Esta página se utiliza como paso intermedio para instalar un nuevo script de usuario en `ScriptCat`.

Después de completar la instalación, esta página debería cerrarse o redirigirse automáticamente.

Esta página no es adecuada para la visualización directa. Si es necesario, visite [Script de instalación](/docs/use/script_installation/).
