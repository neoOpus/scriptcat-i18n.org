ScriptCat es un proyecto de código abierto mantenido por voluntarios, sin ninguna empresa detrás. Los servidores, dominios y otra infraestructura, junto con una gran cantidad de tiempo de desarrollo y mantenimiento, se sostienen gracias al apoyo de la comunidad. Cada contribución ayuda a ScriptCat a ir más lejos.

## A dónde va su patrocinio

Los ingresos del patrocinio se destinan principalmente a:

- **Cubrir los costos de funcionamiento** — servidores, dominios y otra infraestructura cotidiana.
- **Recompensar a mantenedores y colaboradores** — para que los mantenedores de largo plazo y todos los que aportan código, traducciones y documentación reciban la recompensa que merecen.
- **Crear nuevas funciones** — más tiempo para pulir la experiencia y desarrollar nuevas capacidades.

## Cómo patrocinar

Ya sea una persona o una empresa, y sin importar el monto, cada apoyo cuenta.

Recolectamos patrocinios a través de [OpenCollective](https://opencollective.com/scriptcat), con contribuciones únicas o mensuales; su nombre aparecerá en la lista de patrocinadores después de donar.

Si desea una **colocación de patrocinador** — su logotipo e introducción mostrados en el README, en el sitio web o en la documentación — escríbanos a [codfrm@gmail.com](mailto:codfrm@gmail.com).

## Colocaciones de patrocinador

El logotipo y la descripción de un patrocinador se pueden mostrar en los siguientes lugares, acordados por correo electrónico:

| Colocación | Formato |
| --- | --- |
| Parte superior del README de GitHub | Banner grande |
| Área de patrocinadores del README de GitHub | Logotipo + introducción de una línea |
| Página de patrocinadores del sitio web (esta página) | Logotipo + introducción |
| Páginas de documentación del sitio web (p. ej., registro de cambios) | Mostrar logotipo |
