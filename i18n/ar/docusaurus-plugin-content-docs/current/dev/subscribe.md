---
title: وضع الاشتراك
---

يجب أن يبدأ الملف بـ `UserSubscribe` بدلاً من `UserScript`. يجب أن يستخدم رابط التثبيت امتداد `user.sub.js`، ويجب أن يكون رابطاً `https`.

يعرض سكربت الاشتراك مربع حوار التثبيت فقط ليؤكد المستخدم الاشتراك عند التثبيت؛ التحديثات اللاحقة صامتة، ولا يُعرض مربع حوار التحديث مرة أخرى إلا إذا تغير إذن `connect`.

يمكن لسكربت اشتراك واحد وصف روابط التثبيت لعدة سكربتات. تُثبت السكربتات المثبتة عبر وضع الاشتراك بصمت، دون مربع حوار تأكيد، ولا تزال السكربتات المثبتة تظهر في قائمة السكربتات — لكن إذن `connect` الخاص بها يستخدم `connect` المُصرح عنه في الاشتراك بدلاً من إذن `connect` الخاص بالسكربت نفسه.

```js
// ==UserSubscribe==
// @name         xxx
// @description  Subscribe to the xxx script series
// @version      0.1.0
// @author       You
// @connect      www.baidu.com
// @scriptUrl    https://script.tampermonkey.net.cn/48.user.js
// @scriptUrl    https://script.tampermonkey.net.cn/49.user.js
// ==/UserSubscribe==
```

## تحديثات الاشتراك وتحديثات السكربت

وفقاً لـ `فاصل التحديث` الذي يكوّنه المستخدم، يفحص ScriptCat دورياً رابط الاشتراك بحثاً عن التحديثات؛ يجب تكوين `version` لكي يسري هذا المفعول.

يقارن كل تحديث أو تغيير في الاشتراك روابط السكربت بالسكربتات المثبتة حالياً: تتم إزالة السكربتات التي لم تعد موجودة في الاشتراك الجديد، وتُثبت السكربتات المضافة حديثاً بصمت. تتبع تحديثات السكربت `version` الخاص بالسكربت نفسه، باستخدام نفس منطق التحديث المتبع مع السكربت المثبت بشكل عادي.

## التثبيت والتحديث الصامت

تُثبت السكربتات المشتركة وتُحدَّث بصمت — إضافة أو إزالة أو تحديث سكربت من اشتراك يعرض إشعاراً فقط، دون طلب تأكيد المستخدم مرة أخرى. بسبب آلية التحديث الصامت هذه، يرجى الاشتراك فقط في المصادر التي تثق بها.


## البيانات الوصفية

يتغير معنى بعض حقول البيانات الوصفية داخل سكربت اشتراك.

### name

اسم الاشتراك (يمكن أيضاً تحريره مباشرة في قائمة الاشتراكات)

### description

وصف الاشتراك، الذي يصف الغرض من الاشتراك

### version

إصدار الاشتراك. إذا تم حذفه، يتم بدلاً من ذلك تفعيل التحديثات بناءً على ما إذا كان محتوى سكربت الاشتراك قد تغير.

### connect

يطلب إذن الوصول إلى موقع؛ راجع `GM_cookie` و `GM_xmlhttpRequest`. للسكربتات المثبتة عبر وضع الاشتراك، يتم تجاوز `connect` بواسطة `connect` الخاص بالاشتراك.

### scriptUrl

روابط تثبيت السكربت المطلوبة بواسطة الاشتراك
