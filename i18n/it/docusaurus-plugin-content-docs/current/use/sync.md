## Sincronizzazione

Quando uno script viene aggiornato, viene sincronizzato immediatamente con il cloud. Tuttavia, quando i dati nel cloud cambiano, ci vuole del tempo per scansionarli e sincronizzarli localmente. Tenetelo presente quando più dispositivi condividono lo stesso servizio di archiviazione cloud.

Facendo clic su Salva nella sezione di sincronizzazione degli script, verrà eseguita immediatamente una sincronizzazione completa.
