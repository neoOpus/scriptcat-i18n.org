# 🎉 Benvenuto in ScriptCat

Congratulazioni per aver installato con successo l'estensione del browser ScriptCat! ScriptCat è un potente gestore di script utente compatibile con gli script di Tampermonkey e offre molte altre funzionalità potenti.

<GithubStar variant="bar" scene="install" />

## Avviso di sicurezza

⚠️ **Gli script utente hanno capacità potenti, la sicurezza è fondamentale!**

Gli script utente hanno capacità potenti e possono accedere e modificare il contenuto delle pagine web, quindi **la sicurezza è fondamentale**. Per proteggere le vostre informazioni personali e la sicurezza del vostro dispositivo, assicuratevi di:

- ✅ **Installare solo script provenienti da siti di script affidabili**
- ✅ **Esaminare attentamente valutazioni e commenti degli utenti sugli script**
- ✅ **Comprendere la funzionalità e i requisiti di autorizzazione degli script**
- ❌ **Evitare di scaricare script da fonti sconosciute o sospette**
- ❌ **Non installare file di script di origine sconosciuta**

### Fonti di script affidabili consigliate

Vi consigliamo di ottenere gli script dai seguenti siti:

- **[Sito di script di ScriptCat](https://scriptcat.org/)** - Sito ufficiale di script gestito da ScriptCat
- **[GreasyFork](https://greasyfork.org/)** - Il più grande sito di script utente al mondo
- **[Userscript.Zone](https://www.userscript.zone/)** - Script di alta qualità selezionati

## Passaggi successivi

### Accedere all'interfaccia di gestione degli script

Fate clic sull'icona di ScriptCat nella barra degli strumenti del browser, quindi sul pulsante a ingranaggio "⚙️" nell'angolo in alto a destra per accedere all'interfaccia di gestione.

### Ottenere il vostro primo script

Nell'interfaccia popup, fate clic sul menu "⋮" nell'angolo in alto a destra e selezionate "Ottieni script" per andare al sito ufficiale degli script e cercare e installare gli script.

### Esplorare le funzionalità

- 📊 **Gestione degli script**: abilitare/disabilitare gli script, visualizzare lo stato di esecuzione
- 🔧 **Impostazioni personalizzate**: configurare i parametri degli script e le regole di esecuzione
- 📝 **Modifica degli script**: creare e modificare i vostri script
- 🔄 **Sincronizzazione dei dati**: sincronizzare le configurazioni degli script su più dispositivi

## Raccomandazioni d'uso

1. **Iniziare in piccolo**: si consiglia ai nuovi utenti di iniziare con script semplici e ben valutati
2. **Controlli regolari**: controllare e aggiornare regolarmente gli script installati
3. **Eseguire il backup delle configurazioni**: le configurazioni importanti degli script dovrebbero essere sottoposte a backup
4. **Segnalare i problemi**: se incontrate problemi, potete inviare un feedback tramite [GitHub](https://github.com/scriptscat/scriptcat) o la community ufficiale

## Dichiarazione di non responsabilità

Quando utilizzate ScriptCat, dovete comprendere:

- ScriptCat fornisce un ambiente di esecuzione per gli script ma non è responsabile della sicurezza, della funzionalità o del contenuto degli script di terze parti
- Vi assumete voi stessi i rischi dell'utilizzo di script di terze parti
- Si consiglia di leggere attentamente il codice sorgente e la documentazione degli script per assicurarvi di comprenderne la funzionalità

Per i termini completi della dichiarazione di non responsabilità, consultate: [Dichiarazione di non responsabilità completa](/docs/use/policy/disclaimer/)
