ScriptCat è un progetto open source mantenuto da volontari, senza alcuna azienda alle spalle. Server, domini e altre infrastrutture, insieme a una grande quantità di tempo di sviluppo e manutenzione, sono sostenuti dal supporto della community. Ogni contributo aiuta ScriptCat ad andare avanti.

## Dove vanno le sponsorizzazioni

I proventi delle sponsorizzazioni servono principalmente a:

- **Coprire i costi di gestione** — server, domini e altra infrastruttura quotidiana.
- **Ricompensare manutentori e contributori** — affinché i manutentori di lungo corso e tutti coloro che inviano codice, traduzioni e documentazione ricevano la ricompensa che meritano.
- **Costruire nuove funzionalità** — più tempo per rifinire l'esperienza e sviluppare nuove capacità.

## Come sponsorizzare

Che siate un privato o un'azienda, e qualunque sia l'importo, ogni supporto conta.

Raccogliamo le sponsorizzazioni tramite [OpenCollective](https://opencollective.com/scriptcat), con contributi una tantum o mensili; il vostro nome apparirà nell'elenco dei sostenitori dopo la donazione.

Se desiderate una **sponsorizzazione con visibilità** — il vostro logo e una presentazione nel README, sul sito web o nella documentazione — scriveteci a [codfrm@gmail.com](mailto:codfrm@gmail.com).

## Posizioni per gli sponsor

Il logo e la descrizione di uno sponsor possono essere mostrati nei seguenti luoghi, concordati via email:

| Posizione | Formato |
| --- | --- |
| Parte superiore del README di GitHub | Banner grande |
| Area sponsor del README di GitHub | Logo + presentazione di una riga |
| Pagina sponsor del sito web (questa pagina) | Logo + presentazione |
| Pagine di documentazione del sito web (es. changelog) | Visualizzazione del logo |
