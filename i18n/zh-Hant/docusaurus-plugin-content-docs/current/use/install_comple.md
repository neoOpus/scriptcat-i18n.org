# 🎉 歡迎使用 ScriptCat

恭喜您成功安裝了 ScriptCat 瀏覽器擴充功能！ScriptCat 是一個功能強大的用戶腳本管理器，相容於 Tampermonkey 腳本，並提供更多強大的功能。

<GithubStar variant="bar" scene="install" />

## 安全提示

⚠️ **用戶腳本具有強大的能力，安全至關重要！**

用戶腳本具有強大的能力，可以存取和修改網頁內容，因此**安全至關重要**。為了保護您的個人資訊和裝置安全，請務必：

- ✅ **僅從可信的腳本站點安裝腳本**
- ✅ **仔細查看腳本的評分和使用者評論**
- ✅ **了解腳本的功能與權限要求**
- ❌ **避免從未知或可疑來源下載腳本**
- ❌ **不要安裝來源不明的腳本檔案**

### 推薦的可信腳本來源

我們建議您從以下腳本站點獲取腳本：

- **[ScriptCat 腳本站](https://scriptcat.org/)** - 由 ScriptCat 維護的官方腳本站點
- **[GreasyFork](https://greasyfork.org/)** - 全球最大的用戶腳本站點
- **[Userscript.Zone](https://www.userscript.zone/)** - 精心挑選的高品質腳本

## 後續步驟

### 進入腳本管理介面

點擊瀏覽器工具列上的 ScriptCat 圖示，再點擊右上角的「⚙️」齒輪按鈕即可進入管理介面。

### 取得您的第一個腳本

在彈出介面中，點擊右上角的「⋮」選單並選擇「取得腳本」，即可前往官方腳本站搜尋並安裝腳本。

### 探索功能

- 📊 **腳本管理**：啟用/停用腳本、查看執行狀態
- 🔧 **自訂設定**：設定腳本參數和執行規則
- 📝 **腳本編輯**：建立和編輯您自己的腳本
- 🔄 **資料同步**：在多個裝置之間同步您的腳本設定

## 使用建議

1. **從小處開始**：建議新使用者從簡單、評價高的腳本開始
2. **定期檢查**：定期檢查和更新您安裝的腳本
3. **備份設定**：重要的腳本設定應進行備份
4. **回報問題**：如果遇到問題，可以透過 [GitHub](https://github.com/scriptscat/scriptcat) 或官方社群提供回饋

## 免責聲明

使用 ScriptCat 時，您需要了解：

- ScriptCat 提供腳本執行環境，但不對第三方腳本的安全性、功能或內容負責
- 您自行承擔使用第三方腳本的風險
- 建議仔細閱讀腳本的原始碼和文件，以確保您了解其功能

詳細的免責條款請參閱：[完整免責聲明](/docs/use/policy/disclaimer/)
