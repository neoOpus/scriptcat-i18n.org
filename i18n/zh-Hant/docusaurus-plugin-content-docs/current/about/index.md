## 關於 ScriptCat

受 Tampermonkey 設計啟發並與 Tampermonkey 腳本相容，ScriptCat 實現了背景腳本執行框架，並提供一系列特殊 API 讓腳本可以做更多事情，同時配備優秀的編輯器，讓編寫和開發腳本程式碼更加舒適流暢。

關於我們的開發路線圖，請參閱[專案 #1](https://github.com/scriptscat/scriptcat/projects/1)，我們會在那裡發布開發計畫。如果您有任何建議，歡迎開啟 [issue](https://github.com/scriptscat/scriptcat/issues) 告知我們。

**如果您覺得它有用，請考慮給我們一個 Star ❤❤❤**
