# Using VSCode to Develop Scripts

ScriptCat provides a VSCode extension that allows you to write userscripts directly in VSCode. Your changes are automatically synchronized to ScriptCat in your browser upon saving, eliminating the need for manual copy-pasting and significantly boosting development efficiency.

## Preparation

You need to install the following two tools:

1.  **ScriptCat Browser Extension** — If not already installed, please refer to [Quick Start](/docs/use/use/)
2.  **ScriptCat VSCode Extension** — Search for "ScriptCat" in the VSCode Extension Marketplace, or visit the [GitHub Repository](https://github.com/scriptscat/scriptcat-vscode) to download and install.

## Establishing a Connection

After installation, you need to connect the browser extension with VSCode:

1.  Click the ScriptCat icon in your browser to open the management panel.
2.  Go to **Tools > Development & Debugging**.
3.  Find **Automatically connect to VSCode service**, enable it, and click **Connect**.

Once successful, a real-time channel is established between VSCode and ScriptCat.

## Synchronizing Scripts

After the connection is established, you can choose between two methods to sync your scripts:

### Method 1: Automatic Identification Mode (Recommended)

1.  In VSCode, press `Ctrl + Shift + P` (`Cmd + Shift + P` on Mac) to open the Command Palette.
2.  Type and select `scriptcat.autoTarget`.
3.  From then on, every time you open or save a `.user.js` file, it will automatically sync to ScriptCat.

### Method 2: Specified Script Mode

1.  In VSCode, press `Ctrl + Shift + P` (`Cmd + Shift + P` on Mac) to open the Command Palette.
2.  Type and select `scriptcat.target`.
3.  Specify the path of the script file you want to sync.

## Development Workflow

Once set up, the workflow is straightforward:

1.  Write or modify your `.user.js` script in VSCode.
2.  Press `Ctrl + S` to save the file.
3.  The script is automatically synced to ScriptCat in your browser.
4.  Switch to your browser and refresh the page to see the results.

The entire process is manual-free and effective immediately upon saving.

## FAQ

### What if I cannot connect?

*   Confirm that the ScriptCat browser extension is active.
*   Confirm that the ScriptCat VSCode extension is installed and enabled.
*   Check the connection status in the "Development & Debugging" page of the ScriptCat management panel.

### Script not updating after save?

*   Confirm the filename ends with `.user.js`.
*   Confirm you have executed the `scriptcat.autoTarget` or `scriptcat.target` command.
*   Check the VSCode Output panel for any error messages.

### Do I need to reconnect after restarting VSCode?

If "Automatically connect to VSCode service" is enabled, VSCode will reconnect automatically upon restart without manual intervention.
